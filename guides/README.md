# Guides

Step-by-step guides for using this repository:

- [`replicate-results.md`](replicate-results.md): how to reproduce the study's datasets and results, from PubMed data extraction through active learning and the production model to evaluation and post-processing.
- [`new-process-application.md`](new-process-application.md): how to adapt the pipeline to a different biological process (e.g. osteogenesis). It only covers what to change: the queries, concept list, labelling guidelines and GO terms.
- [`model-inference.md`](model-inference.md): how to use the already fine-tuned model on new abstracts: preprocess them, format the input and get a regulator/non-regulator label for each gene.
